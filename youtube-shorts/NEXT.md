# Next videos: "Baby Sunny" good-habits series (5 Shorts)

Format per video: 5 Gemini pictures of the same baby ("Sunny", the sunflower-dungarees baby from Yum Yum Veggies),
~30-35 s, instrumental sing-along style (toy piano melody + band, captions), smooth 60 fps motion, made for kids.
Build with the Yum Yum Veggies pipeline (`veggies_song_audio.py` / `veggies_video.py` pattern).

## How to make the pictures (free, Google Gemini)
1. Open https://gemini.google.com, start a NEW chat for each video.
2. Attach the original baby picture (`assets/veggies/1.png`, the kitchen picture) with the + button.
3. Paste scene 1. Then for scenes 2-5 paste each prompt in the same chat (Gemini keeps the character).
4. If a picture isn't vertical, reply "make it vertical 9:16". If the baby looks different, reply
   "keep the baby exactly like the attached picture".
5. Name the files `<video>-1.png` ... `<video>-5.png` and upload them to the Claude chat.

Add this to the end of EVERY prompt:
`Pixar-style 3D animation still, soft warm lighting, vibrant colors, shallow depth of field, vertical 9:16, no text, no words, no letters`

Grown-ups: show them only from the shoulders down or from behind (hands, apron, jeans). AI tools struggle to
keep adult faces consistent, and the baby is the star anyway.
